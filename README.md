# izi-corp.net — v2

Site statique (HTML/CSS/JS, aucune dépendance), prêt pour GitHub Pages.

- `index.html` : page d'accueil (hero, services, avant/après, estimateur, méthode, engagements, FAQ, contact)
- `css/site.css` : tous les styles (tokens en tête de fichier)
- `js/site.js` : interactions ; la grille tarifaire de l'estimateur est la constante `GRILLE`
- `mentions-legales.html`, `confidentialite.html`, `404.html`
- `assets/img/` : photos ; `assets/og-izicorp.png` : image de partage (1200×630)
- `CNAME`, `robots.txt`, `sitemap.xml`

Formulaire : Web3Forms (même clé que la v1). Contact : WhatsApp 05 44 05 84 84.

Mise en ligne : remplacer le contenu du dépôt `izi-corp.net` par ce dossier, puis pousser sur `main`.
Les anciens fichiers `style.css`, `IDEA.md` et `design/` peuvent être retirés.
